# Epic Pro skill
Claude skill for pro video editing: instructions, CC0 SFX, transitions, fonts, 3D sources, audio generation tool, dev environment.

Install: download the repo as ZIP (Code > Download ZIP), then zip only the `epic-pro/` folder so that `SKILL.md` sits at the root of the zip, and upload it in Claude -> Settings -> Skills.

See `SOURCES.md` for every source and licence.
